# Registro de incidentes

Un archivo por incidente, nombrado `AAAA-MM-DD-descripcion-corta.md`.

El registro es **obligatorio para toda brecha de datos personales, se notifique o
no** (GDPR Art. 33.5). Un incidente que se decidió no notificar igual se anota,
con el motivo de esa decisión: eso es exactamente lo que una autoridad va a pedir
ver si algún día pregunta.

Qué lleva cada archivo está en `../incident-response.md`.

Hoy está vacío, y eso es información: no hubo ninguno, o no nos enteramos. Dado
que no hay detección configurada, las dos lecturas son posibles.
