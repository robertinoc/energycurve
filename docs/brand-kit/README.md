# EnergyCurve Brand Kit — v1

Approved V1 of the EnergyCurve brand system. *Shape the curve. Own the dancefloor.*

## Contents

- **EnergyCurve Brand Kit.dc.html** — the interactive brand guide (open in a browser). Covers essence, logo, color, typography, voice & tone, the signature energy curve, and UI components.
- **CLAUDE_IMPLEMENTATION_PROMPT.md** — master prompt for Claude / Claude Code to implement this design system in the EnergyCurve app. Paste it into Claude at the repo root (`~/Documents/code/energycurve` or github.com/robertinoc/energycurve) and copy `assets/` into the app first.
- **assets/** — official logo files:
  - `logo-horizontal-trans.png` — primary lockup (transparent)
  - `logo-icon-lockup-trans.png` — stacked lockup (transparent)
  - `logo-horizontal.png`, `logo-icon-lockup.png` — on-background versions
  - `app-icon.png`, `app-icon-standalone.png` — app icon
  - `logo-greyscale.png` — greyscale variant
